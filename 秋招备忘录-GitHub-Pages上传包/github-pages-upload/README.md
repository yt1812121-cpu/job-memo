# 秋招备忘录

可直接部署到 GitHub Pages 的静态网页。

发布步骤：

1. 在 GitHub 创建一个 Public 仓库，名称可用 `job-memo`。
2. 进入仓库，选择 **Add file → Upload files**。
3. 上传本文件夹中的 `index.html` 和 `.nojekyll`，完成提交。
4. 打开 **Settings → Pages**。
5. 在 **Build and deployment** 中选择 **Deploy from a branch**。
6. Branch 选择 **main**，文件夹选择 **/(root)**，然后保存。

稍等几分钟，GitHub 会显示可分享的网址。
